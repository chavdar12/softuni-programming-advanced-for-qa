# SoftUni Programming Advanced for QA

Solutions for the SoftUni Programming Advanced for QA course. Lectures 002–019 and 026 are C# on .NET 10 with NUnit
tests: every lecture folder is its own solution (`NNN-Lecture/NNN-Lecture.slnx`) and every exercise has a `Tests`
project next to it. Lectures 020–025 are JavaScript, one npm project per lecture, tested with Mocha + Chai.
